# News App 📰

A Flutter mobile application that provides the latest news, fetching data from a public API. The app organizes articles into categories for easy browsing, including:

- Sports ⚽
- Science 🔬
- Technology 💻
- Entertainment 🎬
- Health 🏥

## Features
- Browse news by category
- Pull-to-refresh news feed
- Clean and responsive Flutter UI
- Uses a public API to fetch live data
